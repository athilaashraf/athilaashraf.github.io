  • Python
  • Streamlit
  • Groq Whisper
  • Groq LLaMA
Watch demo video View code on GitHub
Problem
Everyday tasks like writing code, creating files and summarising text should work by voice.
Solution
It transcribes speech, uses an LLM to sort each request into one of four intents (code generation, file creation, summarisation, chat), and runs it through a modular tool engine.
Result
I tested local Whisper against a hosted speech API and moved to the hosted one because the local version was too slow and memory-heavy.
